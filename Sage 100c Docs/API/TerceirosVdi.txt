TerceirosVdi
Entidade Terceiros VDI. Manutenção directa á tabela.

Membros (12):

  [Function] Alterar
    Output: Long - Se <>0 deu erro
    => Alterar registo existente desta entidade na base de dados

  [Function] HerdarPropriedades
    Input : ByVal Tipodoc As String, ByVal NumDoc As Long, ByVal Serie As Integer, ByVal Ano As Integer
    => Clona os dados da entidade passada por parâmetro (lê a outra entidade e passa as suas propriedades para esta)

  [Function] Inserir
    Output: Long - Se <>0 deu erro
    => Insere registo desta entidade na base de dados

  [Function] Ler
    Input : ByVal Tipodoc As String, ByVal NumDoc As Long, ByVal Serie As Integer, ByVal Ano As Integer, Optional ByVal FichXML As String = ""
    Output: Long - <>0 = Erro
    => Lê o registo da entidade da base de dados, opcionalmente pode ser passado um fx (percurso\nome) XML com os dados e a aplicação lê desse fx.

  [Function] Remover
    Output: Long - Se <>0 deu erro
    => Remover (apagar) registo existente desta entidade na base de dados

  [Function] UltimaMensagem
    Output: String
    => Retorna a ultima mensagem emitida pela API

  [Function] UltimoErro
    Output: String
    => Retorna o ultimo Erro emitido pela API

  [Function] Validar
    Input : Optional ByVal Operacao As Integer
    Output: integer - -1 = Erro
    => Verifica se os dados que constam nas propriedades são válidos para de seguida se poder efectuar inserção, alteração, anulação

  [Sub] Class_Initialize
    Output: Loga erro se não conseguir ligar á base de dados
    => Ligar as camada de dados

  [Sub] Class_Terminate
    => Desligar as camadas de dados

  [Sub] CopiaDados
    => Passa a informação do interface para a camada de dados para posterior inserção, alteração, remoção. Pode ter algum processamnto, transformação da informação

  [Function] XML
    Output: Long
    => Lê entidade para memória a partir de fx xml
